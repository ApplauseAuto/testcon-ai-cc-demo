# UI Style Guide

## Colours

Primary buttons use the brand teal. Destructive actions (delete, cancel order)
use red and always require a confirmation dialog.

## Typography

Headings use the display font at 28px; body text is 15px with 1.5 line height.
Never use more than two font weights on one screen.

## Empty states

Every list view needs an empty state with an illustration, one sentence of
explanation, and a single primary call to action.
